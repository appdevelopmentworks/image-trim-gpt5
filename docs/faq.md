# よくある質問 (FAQ)

## 1. 基本機能

### Q1. どの画像フォーマットに対応していますか？
JPG / PNG / WebP の読み込みと出力に対応しています。RAW や HEIC は現状サポート外です（将来の issue backlog に登録済み）。

### Q2. トリミング後の画像はどこに保存されますか？
ブラウザ/Electron 内で完結しており、サーバーにアップロードされません。書き出し時に単体ファイルまたは ZIP アーカイブが生成され、ダウンロードフォルダに保存されます。

### Q3. 何枚まで一括処理できますか？
PoC 時点では 10 枚を推奨上限とし、10 枚を 30 秒以内に処理する KPI を達成しています。大量バッチ処理は今後の issue で最適化予定です。

## 2. トラブルシューティング

### Q4. 画像追加時に何も起きません。
- 対応フォーマットか確認してください（`image/*` の MIME が必要）。
- ブラウザのセキュリティ設定でファイルアクセスがブロックされていないかチェックしてください。

### Q5. トリミングの保存が反映されない。
- 各カード右下の「調整する」ボタンからトリミングモードを開き、「トリミングを保存」ボタンを押す必要があります。
- 保存後にカードに「トリミング済み」と表示されるか確認してください。

### Q6. ZIP ダウンロードが開始されない。
- Popup/ダウンロードのブロック機能が有効なブラウザだとダイアログが抑止される場合があります。許可リストに追加してください。
- 1件のみ処理した場合は ZIP ではなく単体ファイルをダウンロードします。

### Q7. Canvas ベンチが 30 秒を超えました。
- 実行環境によっては CPU/GPU プロファイルで差が出ます。`pnpm bench:canvas` 実行時に `CANVAS_BENCH_BATCH` を下げるなど、KPI 監視用にログを添えて Issue を報告してください。

## 3. 開発者向け

### Q8. CI でどのコマンドが実行されますか？
GitHub Actions (`.github/workflows/ci.yml`) で `pnpm lint` → `pnpm vitest run` → `pnpm bench:canvas` → `pnpm build:web` を実行します。失敗時はログと再実行結果を PR にコメントしてください。

### Q9. Electron 版で ZIP 処理は利用できますか？
現在は Web 版のみ。Electron 版では Phase3 で IPC 経由のファイル保存処理を組み込む予定です。それまでは Web フローを参照してください。

### Q10. ベンチ/ZIP 処理を再利用するには？
`scripts/benchmarks/canvas-benchmark.ts` と `src/components/features/SettingsPanel.tsx` を参照し、共通ロジックは `src/lib/image-process.ts` / `src/lib/utils.ts` に集約されています。Electron 側では IPC で Blob を受け取り、`file-saver` 部分を OS ネイティブ保存に置き換える計画です。
